# فاتورة - منشئ الفواتير للمستقلين

## 🎯 نظرة عامة
"فاتورة" هو تطبيق ويب بسيط لإنشاء وإدارة الفواتير للمستقلين والشركات الصغيرة في الوطن العربي.

## ✨ المميزات
- ✅ إنشاء فواتير احترافية
- ✅ إدارة العملاء
- ✅ تتبع حالة الفواتير (مدفوعة / مستحقة / متأخرة)
- ✅ تصدير PDF (عبر الطباعة)
- ✅ حساب الضريبة تلقائياً
- ✅ واجهة عربية سهلة الاستخدام

## 🚀 التشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق
```bash
python app.py
```

### 3. فتح المتصفح
افتح الرابط: http://localhost:5000
